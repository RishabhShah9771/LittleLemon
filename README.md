# Little Lemon Restaurant Website

Little Lemon is a responsive restaurant website built with React.

## Features

* Responsive layout for desktop and mobile
* Restaurant homepage
* Navigation between pages
* Weekly specials section
* Customer testimonials
* About section
* Table reservation form
* Accessible and semantic design

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* React Router
* Vite

## Run the Project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
